# Многоуровневая защита LLM-консультанта интернет-магазина

Экспериментальный стенд, код и данные к научной статье:
**«Многоуровневая защита LLM-консультанта интернет-магазина от джейлбрейк-атак и нецелевого использования»**
*(Multilevel Protection of an LLM-Based Online Store Assistant against Jailbreak Attacks and Off-Topic Misuse)*.

## О проекте

Репозиторий содержит воспроизводимую реализацию многоуровневой схемы защиты клиентского LLM-ассистента (на примере консультанта интернет-магазина бытовой техники и электроники «ТехноМир») от джейлбрейк-атак, промпт-инъекций и нецелевого использования, а также скрипт для полного прогона экспериментов, абляционного анализа и анализа чувствительности порогов.

### Уровни защиты

| Уровень | Описание |
| :--- | :--- |
| **L0** | Без внешнего фильтра (только системный промпт модели). |
| **L1** | Словарный (keyword) фильтр на основе 24 стоп-слов и основ. |
| **L2** | Классификатор предметной области (`TF-IDF` по словам и символьным n-граммам + логистическая регрессия). |
| **L3** | Полный входной фильтр: `L2` + нормализация/деобфускация (Base64, гомоглифы, leet, разрядка, обратная транслитерация) + сигнатуры инъекций + сегментный анализ смешанных намерений. |
| **L4** | Выходной валидатор ответов модели (проверка кода, несанкционированных обязательств, аномальных цен, утечки системного промпта по «канарейке» и n-граммам, дискредитации бренда и тематический классификатор). |

## Структура репозитория

| Файл | Описание |
| :--- | :--- |
| [`data_train.py`](data_train.py) | Генератор синтетической обучающей выборки по шаблонам (3000 примеров: 1500 целевых, 900 нецелевых, 600 атак; без реальных пользовательских данных). |
| [`data_test.py`](data_test.py) | Тестовая выборка, составленная вручную (300 запросов, 10 категорий: 105 допустимых, 195 подлежащих блокировке). |
| [`data_resp.py`](data_resp.py) | 60 модельных ответов ассистента (30 корректных и 30 с нарушениями) для оценки выходного валидатора `L4`. |
| [`guard.py`](guard.py) | Реализация уровней входной защиты `L0–L3`, нормализации, сигнатур, сегментации и выходного валидатора `L4`. |
| [`run.py`](run.py) | Запуск полного эксперимента (5 сидов, бутстрэп 95% ДИ, абляция `L3`, анализ порогов, оценка `L4`); сохраняет результаты в `results.json`. |
| [`results.json`](results.json) | Зафиксированные результаты эксперимента, приведённые в статье. |
| [`requirements.txt`](requirements.txt) | Зависимости Python. |

## Основные результаты

### Входная защита (`L0–L3`, 300 тестовых запросов, `seed=0`)

| Уровень | TBR (полнота блокировки) | FRR (ложные отказы) | Precision | F1 | Задержка (CPU) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **L0** | 0.0% | 0.0% | 0.0% | 0.000 | 0.00 мс |
| **L1** | 45.1% | 11.4% | 88.0% | 0.597 | 0.002 мс |
| **L2** | 82.6% | 5.7% | 96.4% | 0.890 | 1.09 мс |
| **L3** | **89.2%** *(95% ДИ: 84.7–93.3%)* | **8.6%** | 95.1% | **0.921** | **0.97 мс** |

Абляционный анализ показал, что добавление сегментного анализа в `L3` повышает долю блокировки нецелевых запросов, замаскированных под вопросы к магазину (`ATK_smuggle`), с **57%** до **77%**.

### Выходной валидатор (`L4`, 60 ответов)

| Конфигурация | Recall | FPR | Precision | Задержка (CPU) |
| :--- | :---: | :---: | :---: | :---: |
| Только правила | 53.3% | 0.0% | 100.0% | 0.03 мс |
| Правила + классификатор | **66.7%** | 3.3% | 95.2% | 0.77 мс |

## Воспроизведение эксперимента

### Требования

- Python 3.10+ (в статье использовались Python 3.13 и `scikit-learn` 1.9.1 на 2 vCPU без GPU)
- `numpy`, `scikit-learn`

### Установка и запуск

```bash
git clone https://github.com/MrMixaDj32/llm-assistant-multilevel-guard.git
cd llm-assistant-multilevel-guard

python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows (PowerShell):
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
python run.py
```

Время полного прогона на 2 vCPU — около 10 секунд. GPU не требуется. Итоговые метрики выводятся в консоль и сохраняются в `results.json`.
